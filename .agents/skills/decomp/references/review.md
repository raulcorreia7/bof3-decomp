# Review

Input: a diff or a range. `check` proves the bytes; this pass is for the reader. Rules:
[docs index](../../../../docs/README.md). Fix what the grant allows; a `needs:` line names the file
and line.

1. Set the diff: `D=$(git diff main...HEAD -- src include config)` (or the range).
2. Run the quality pass below on it, one row at a time, until every row is read.
3. List one finding per line: `file:line class fix`, then the count per class.

## Quality pass

| Check                  | Command                                                                                                                   | Fix                                                                                                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Declarations in a `.c` | `git diff main...HEAD -- 'src/**/*.c' \| rg '^\+(extern \|\w[\w *]+\()'`                                                  | move to the owning header ([layout](../../../../docs/conventions.md#lowest-scope-wins))                                                              |
| Duplicate declaration  | `rg -n 'extern .*\bNAME\b' src include` for each new extern                                                               | delete the copy; include the owner                                                                                                                   |
| Views and aliases      | `rg '^\+#define \w+ +(func\|D)_[0-9A-F]{8}\b' <<<"$D"`; `rg '^\+.*\*\((u\|s)(8\|16\|32) ?\*\)&' <<<"$D"`                  | `config/symbols.toml` row with `source`; type the one declaration                                                                                    |
| Reads like source      | read each changed body as its 1997 programmer would have written it                                                       | rewrite casts, offsets, member chains and twice-written values ([the rule](../../../../docs/conventions.md#write-it-as-the-original-programmer-did)) |
| Cast calls and returns | `rg '^\+.*\(\(\w[\w ]*\(\*\)\(' <<<"$D"`; `rg '^\+.*\(\w+ ?\*+\) ?\w+\(' <<<"$D"`                                         | fix the prototype's parameter or return type ([types](../../../../docs/conventions.md#types-and-values))                                             |
| Includes               | `git diff main...HEAD -- 'src/**/*.c' \| rg '^\+#include'`                                                                | a `.c` includes only the headers for the names it uses                                                                                               |
| Raw retail addresses   | `rg '^\+.*\b0x(80\|1F80)[0-9A-Fa-f]{4,6}\b' <<<"$D"`                                                                      | the named global ([values](../../../../docs/conventions.md#values))                                                                                  |
| Mechanical names       | storage words, widths, offsets, counts, addresses, `And` or a step list in a new name; a family of 3+ in verb-first order | the [natural-names test](name.md#natural-names), or keep the address name                                                                            |
| Comments               | new comments that retell code, history, evidence or tools                                                                 | delete; evidence goes in the commit body ([comments](../../../../docs/conventions.md#comments))                                                      |
| Storage words          | `rg '^\+.*\b\w*(Word\|Half\|Byte\|Ref\|View\|Window\|Row\|Scratch\|_ADDRESS\|_OFFSET)\b' <<<"$D"`                         | game name ([names](../../../../docs/conventions.md#names), [storage words](../../../../docs/conventions.md#storage-words))                           |
| Loose globals          | new adjacent `extern`s at one base, stride or clear                                                                       | one struct, array or union ([records](../../../../docs/conventions.md#globals-are-records))                                                          |
| Names without facts    | `rg '^\+\w+ = 0x' <<<"$D"`                                                                                                | the commit body cites the evidence                                                                                                                   |
| Fragments              | a new `.h` or macro that holds part of a function; `bin/coddog cluster <target>` on touched images                        | one game name, whole body ([shared bodies](../../../../docs/conventions.md#shared-bodies))                                                           |
| Accessor macros        | a new macro that reads or writes a typed global                                                                           | member access (`g_PARTY_Members[i].hp`)                                                                                                              |
| Magic values           | new bare numbers in conditions, strides and stores                                                                        | a named constant or flag when the users give one meaning                                                                                             |
| Aids                   | `rg '^\+.*(MATCH_REG\|MATCH_FAKE_PIN\|CLOBBER_\|MATCH_FAKE_OPAQUE)' <<<"$D"`                                              | reorder, pointer local or a benign helper first; keep the `FAKE:` note                                                                               |
| Style                  | mixed declarations, `for` declarations, `_Bool`, anonymous unions, casts a typed declaration removes                      | C89 ([language](../../../../docs/conventions.md#language-and-formatting))                                                                            |
| Dead and stale         | stale comments, unused locals and includes near the change                                                                | delete                                                                                                                                               |
| Format                 | `meson compile -C build/meson format-check`                                                                               | `meson compile -C build/meson format`                                                                                                                |

A clean pass says so and names the range it read.

## Pull request

Input: a PR number or branch. The quality pass above covers each line; this pass covers what a
line-by-line read misses. Read the diff with `gh pr diff <n> -R raulcorreia7/bof3-decomp`, then go
through every row. Report one finding per line: `file:line class fix`. End with `APPROVE`, or with
`CHANGES` and the counts per class.

| Check                     | How                                                                                                                                  | Pass when                                                                                                                                                                                                                                                         |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Scope                     | `git diff --stat main...HEAD` against the PR's stated scope                                                                          | Only the PR's own files change. A merge commit that carries an older tree shows up here as unrelated files and reverted work.                                                                                                                                     |
| Bytes                     | `meson compile -C build/meson pre-push` on the exact head, plus `check-<image>` for each image a changed header or signature reaches | 428 images match. No `MATCH` turns into `NON_MATCHING` or `INCLUDE_ASM`, and no compiler or maspsx flag changes.                                                                                                                                                  |
| Nothing lost              | the `kept`, `addrs` and `markers` pre-push rows                                                                                      | No named define, global, member, type or function is lost or degraded, and every address survives. A deliberate removal has a `Kept-Removed:` line.                                                                                                               |
| Shared code               | each new or changed shared body or macro                                                                                             | It sits inside each image's own function, as a `static inline` or a statement macro, with the fewest arguments. It never takes the function name, and there are no per-image `#define` switches ([shared bodies](../../../../docs/conventions.md#shared-bodies)). |
| Duplication goes down     | `tools/dups.py near --full` and `bin/coddog cluster <target>` on touched images                                                      | The PR leaves fewer copies than it found. A sequence repeated across images uses the small helper the original team would have written once.                                                                                                                      |
| Records                   | new adjacent globals, `[N][stride]` views, raw offsets, and calls that pass one record's fields one by one                           | They are one struct, array or union, defined once in the owning subsystem header. A callee that treats values as one thing takes the record.                                                                                                                      |
| Values                    | new literals in conditions, strides, stores, switch cases and loop bounds                                                            | An existing name is used where one fits (ability, item and enemy enums, `COORD_HALF`, `TO_COORD`, `_COUNT`s). Pixels and counts are decimal; masks and offsets are hex.                                                                                           |
| Names                     | every new or changed name                                                                                                            | It says the game purpose in developer terms, fits its entity across every related enum, table and field, and never embeds an address. A state table is `<Domain>States` with an enum ending in `_COUNT`. An unknown purpose keeps `func_`/`D_`.                   |
| Touched files left better | each file the PR touches                                                                                                             | No magic value, stale comment, missing blank line between blocks, or cast a typed view removes is left in the lines around the change.                                                                                                                            |
| History                   | the PR title, body, commit messages and branch name                                                                                  | No model, agent-tool or model-named lane appears, and there is no `Co-authored-by` trailer. The author is `raulcorreia7 <raulcorreia7@users.noreply.github.com>`.                                                                                                 |
| Description               | the body against `.github/PULL_REQUEST_TEMPLATE.md`                                                                                  | Summary; Changes with bold topics, indented one-fact bullets and old → new tables; Left; Checks ticked only for what ran on this head.                                                                                                                            |
| Merge                     | `gh pr view <n> --json autoMergeRequest`                                                                                             | Squash auto-merge is set. A contributor's PR merges with `--rebase`, so its authors are kept.                                                                                                                                                                     |
