# Subsystems

Which part of `src/` does which job, which records and headers it owns, and how much readability debt it holds. The path rules are in [conventions: files and headers](layout.md#files-and-headers). The metrics are defined in [tools: quality](../tools/README.md#quality).

## Map

Every `src/` directory belongs to one row (the engine rows follow `src/engine/<module>`), except `overlays/area/area175` to `area185`: the Area row and the Fairy Village row both name them. A `Name.h` shared body sits at the folder named in its row. `tools/tests/test_subsystems_doc.py` fails when a row names a directory, header or record that does not exist.

The Menu row's `shop` folder keeps the disc name SHOP.EMI, which is not only the shop. Its `g_MenuScreenSteps` run
the town screens a field actor or `Scene_RunInn` opens: buying and selling (`Shop_`), the inn with its save screen
(`SAVE_`), inoculations, the party swap and skill ink. Its panels (`Menu_`) are shared with the START, BATE and
SHISU overlays.
